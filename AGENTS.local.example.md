# Локальные инструкции пользователя

> Этот файл — пример. Скопируй его в `AGENTS.local.md`. Сам `AGENTS.local.md` исключён из Git и читается агентом **после** `AGENTS.md`.

## Пользовательские команды

Здесь можно объявлять локальные alias-команды и короткие workflows.

Пример:

```text
DEPLOY PREVIEW
→ запусти локально описанный preview workflow проекта; не деплой production.
```

## Личные предпочтения

Пример:

- перед destructive migration всегда показывать plan и ждать отдельной команды;
- локально использовать конкретный test runner command;
- предпочитать определённый формат отчёта.

## Ограничения

Локальные инструкции могут **расширять** Harness и задавать пользовательские предпочтения, но не должны скрыто отменять safety rules, Accepted ADR, scope текущего STEP, deterministic gates или repository security policy.
