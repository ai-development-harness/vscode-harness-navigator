# Planning

- `PLAN.md` — roadmap projection.
- `STATUS.md` — project execution projection.
- `tasks/STEP-NNN.md` — canonical task contracts.
- `reviews/` — immutable review reports.
- `audits/` — reconciliation/audit reports.
- `releases/` — release checks.

Не используй PLAN как место для полной спецификации задачи: детали принадлежат task-файлу.
