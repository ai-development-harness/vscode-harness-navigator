## Findings

### F-001 — Статическая проверка bundle не ловит часть write API, Evidence утверждает обратное

**Severity:** medium
**Category:** evidence
**Location:** scripts/packageInspection.ts:53-132; src/test/integration/mvp/boundary.test.ts:89-90; planning/tasks/STEP-007.md Evidence
**Scenario:** vscode.workspace.fs.{delete,rename,createDirectory,copy}, async node:fs (rm/unlink/mkdir/rename/promises.*), require с backtick и openExternal/saveAll не ловятся inspect:package; runtime spies эти vscode.workspace.fs API не перехватывают.
**Impact:** Evidence обещает защиту от мутаций, которой нет; inspect:package может дать ложный PASS в security-sensitive STEP.
**Fix direction:** Добавить запрет \bworkspace\.fs\b, async fs write names, openExternal/saveAll, backtick/нелитеральный require; unit-кейсы в packageInspection.test.ts; исправить формулировку Evidence и комментарий boundary.test.ts.

### F-002 — Summary view использует basename root как TreeItem.id

**Severity:** medium
**Category:** implementation
**Location:** src/views/summaryView.ts getTreeItem/itemsFor
**Scenario:** Два root с одинаковым basename (/a/app и /b/app) дают одинаковые id, VS Code отклоняет дерево.
**Impact:** Обязательное MVP-представление не работает в корректной multi-root конфигурации; tooltip Status Bar неразличим.
**Fix direction:** Строить id от folder.uri.toString() (передать URI/ключ в RootSummary); добавить тест с двумя root с одинаковым именем.

### F-003 — Skip-маркеры и refresh fallback ослабляют доказательство containment, taxonomy и watchers

**Severity:** medium
**Category:** evidence
**Location:** src/test/integration/mvp/mvpFlows.test.ts:143-147,172-200,250-258; watchers.test.ts:118-200; support/helpers.ts
**Scenario:** Маркер skipped-fixtures.json молча пропускает root; при маркере mvp-unreadable this.skip() идёт до assert остальных 11 категорий; уровень 2 допускает один refresh fallback из трёх.
**Impact:** Acceptance по containment на каждой platform, 12 категориям и watcher-driven refresh подтверждён слабее заявленного.
**Fix direction:** Утверждать пустой skipped-fixtures.json на Linux/macOS (allowlist по platform); сначала assert 11 категорий, потом skip последней; зафиксировать допуск fallback в STEP или сделать hard assert на тип файла.

### F-005 — Runtime symlink-тест тихо проходит при отказе OS; на win32 file-symlink создаётся как junction

### F-007 — ZIP reader без ограничения объёма распаковки

### F-008 — Независимость источника SHA-256 в packaged identity не подтверждена
