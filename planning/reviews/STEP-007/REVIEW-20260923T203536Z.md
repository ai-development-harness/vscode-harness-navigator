### F-001 — Taxonomy-тест безусловно падает там, где UnexpectedInternalError разрешено пропускать

**Severity:** high
**Category:** implementation
**Location:** src/test/integration/mvp/mvpFlows.test.ts:262
**Scenario:** При маркере mvp-unreadable (uid 0 или Windows) UnexpectedInternalError не наблюдается; после проверки mustObserve остаётся assert.deepEqual(missing, []), который падает раньше this.skip() (строка 266).
**Impact:** Правка F-003 предыдущего review неработоспособна: разрешённый allowlist-ом случай даёт ложный FAIL и провоцирует ослабление assert.
**Fix direction:** Удалить assert.deepEqual(missing, []) на строке 262; оставить mustObserve, this.skip() только при unreachable.length > 0.

### F-002 — Static scan bundle обходится деструктуризацией workspace и другими обычными формами

**Severity:** medium
**Category:** evidence
**Location:** scripts/packageInspection.ts:53-81; planning/tasks/STEP-007.md Evidence (строка про workspace.fs)
**Scenario:** esbuild-выход `let{fs:c}=n.workspace;await c.delete(...)` / createDirectory / copy, openSync(p,'w'), fs["rm"], require("node:child_"+"process"), process.binding, executeCommand с terminal/tasks id проходят inspectPackage с 0 violations (синтетические probe, esbuild --minify).
**Impact:** Для vscode.workspace.fs.* нет runtime-перехвата, static scan — единственный контроль, и он даёт ложный PASS на обычной форме кода; противоречит требованию плана «без ложного PASS».
**Fix direction:** Добавить токены: \bcreateDirectory\b, \.copy\(, \}=[\w$]+\.workspace\b, \.workspace\[, \bO_(WRONLY|RDWR|CREAT|TRUNC|APPEND)\b, openSync\([^,()]+,", process\.(binding|dlopen), createRequire, require\(\s*["'][^"']*["']\s*\+; executeCommand — allowlist литеральных id (vscode.open, harnessNavigator.*, workbench.view.extension.harnessNavigator); unit-тест на esbuild-выход с {fs}; проверить 0 совпадений на текущем dist; переформулировать Evidence как best-effort denylist.

### F-003 — Packaged-профиль может пройти без проверки identity

**Severity:** medium
**Category:** evidence
**Location:** src/test/integration/mvp/packagedIdentity.test.ts:9-16; .vscode-test.mjs; package.json test:packaged
**Scenario:** packaged определяется по наличию __packaged_tests__ в __dirname; если packaged-профиль запустит suites из dev-пути, тест молча делает this.skip(), vscode-test завершается с кодом 0.
**Impact:** Acceptance «реальный packaged extension работает offline» может быть засчитан без реального запуска packaged bundle.
**Fix direction:** Передавать признак профиля через env/launchArgs и в packaged-профилях считать packaged===false FAIL, а не skip.

### F-004 — Частичный skip containment-фикстур проходит зелёным

**Severity:** medium
**Category:** evidence
**Location:** src/test/integration/mvp/mvpFlows.test.ts:170-200
**Scenario:** При отказе OS в одной из четырёх containment-фикстур тест продолжает и skip только если пропущены все четыре; mvp-valid-symlink-file (STEP-991) при маркере пропускается молча. На Linux/macOS защищает allowlist, на Windows — нет.
**Impact:** На non-Linux пропущенные фикстуры не доказывают containment, но результат зелёный.
**Fix direction:** Traversal и absolute проверять всегда; на платформах, где допустим маркер, помечать тест partial (skip с перечнем пропущенных фикстур после assert остальных) и фиксировать каждую в Evidence.
