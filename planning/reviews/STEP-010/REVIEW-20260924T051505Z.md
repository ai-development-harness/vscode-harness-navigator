### F-002 — Проверка PNG-чанков останавливается на IEND, не требует IDAT и не проверяет CRC

**Severity:** low
**Category:** implementation
**Location:** scripts/packageInspection.ts inspectIcon
**Scenario:** После IEND можно дописать tEXt/iTXt или любые байты — запрет текстовых чанков обходится, secret heuristics для PNG не применяются; PNG из одних IHDR и IEND без IDAT проходит; испорченный CRC чанка проходит inspection.
**Impact:** Критерий «валидный PNG» и запрет метаданных проверяются неполно.
**Fix direction:** После IEND требовать offset === data.length, требовать хотя бы один IDAT, проверять CRC каждого чанка (crc32 есть в iconEncoder); unit-кейсы: данные после IEND, нет IDAT, битый CRC.

### F-003 — Правила README проверяют переписанный vsce текст, сравнение с исходником пропускается молча и не покрыто тестами

**Severity:** low
**Category:** implementation
**Location:** scripts/packageInspection.ts inspectReadme; scripts/inspect-package.ts
**Scenario:** vsce переписывает относительные ссылки в https://github.com/.../blob/HEAD/..., поэтому regex на ](docs/ на реальном VSIX не срабатывает; regex не ловит ](/docs/, ](../docs/, HTML src/href, reference-style; правило про #<число> из плана отсутствует; при отсутствии docs/marketplace/README.md сравнение пропускается без уведомления; inspect-package.ts тестами не покрыт.
**Impact:** Возможны ссылки на приватные пути или битые ссылки на вкладке Details при ложном PASS.
**Fix direction:** Применять правила к исходному README и ловить переписанную форму /blob/HEAD/(docs|planning|.harness)/; расширить regex (../, /, src=, href=, reference-style, #<число>); вынести сравнение README в чистую функцию с unit-тестом; при пропуске сравнения печатать явное уведомление.

### F-004 — README для Marketplace относит скрытые и контекстные команды к Command Palette

**Severity:** low
**Category:** implementation
**Location:** docs/marketplace/README.md, раздел Commands (Command Palette) и русский аналог
**Scenario:** copyArtifactId, copyArtifactPath, copyCommand имеют when:false в menus.commandPalette; findAllReferences и showRelations доступны только при editorLangId == markdown.
